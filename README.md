Smart Medical Transport & Logistics SystemA desktop application designed to simulate a smart, zone-based dispatch system for medical logistics. It prioritizes emergency requests, manages specialized vehicles (Ambulances, Cold-Chain Vans), and provides real-time tracking and comprehensive logging.✨ FeaturesThis system models key features required for efficient medical and emergency dispatch:Triage and Prioritization: Automatically assigns the most suitable vehicle (always an Ambulance for emergency categories like "Cardiac Arrest") based on the request's medical severity.Zone-Based Dispatch: Implements a logistics strategy where requests are matched to the nearest available vehicle based on predefined geographical Zones (A, B, C) to minimize response time.Critical Cargo Monitoring: Simulates real-time Cold-Chain tracking for sensitive cargo (e.g., vaccines, organs). The system triggers a critical SOS alert and logs the failure if the simulated temperature exceeds the safe limit.Role-Based Views: Provides three distinct user interfaces for different stakeholders:Hospital / Clinic: To submit requests with specific medical and logistical requirements.Driver Dashboard: To accept assigned jobs and initiate the simulated transit tracking.Admin / Logistics Panel: To monitor all active requests, force-assign vehicles, and view system statistics.Auditable Logging: Automatically generates detailed text-file reports for every job:transport_logs.txtdelivery_report.txtcold_chain_alerts.txt💻 Technologies UsedLanguage: JavaGUI Toolkit: Java SwingData Handling: Standard Java Collections (ArrayList) and File I/O (FileWriter) for persistence and logging.🚀 Getting StartedPrerequisitesYou need a Java Development Kit (JDK) installed to compile and run the code.Installation and RunClone the Repository:Bashgit clone https://github.com/your-username/smart-medical-logistics.git
cd smart-medical-logistics
Compile the Java Files:You must compile all six Java files (Main.java, Request.java, Vehicle.java, LogisticsManager.java, BookingForm.java, and DriverDashboard.java).Bashjavac Main.java Request.java Vehicle.java LogisticsManager.java BookingForm.java DriverDashboard.java
Run the Application:Execute the main class to launch the system's interface:Bashjava Main
